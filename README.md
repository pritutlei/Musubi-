## ✨ Features Included

1. **Brand & Hero Section**:
   - Modern, appetizing street-food design (Hawaiian & Japanese inspired).
   - Animated visual graphics of freshly pressed Spam Musubi with nori and egg.
   - Quick action buttons to browse menu or jump to deals.

2. **Smart 3-for-₱100 Bundle Calculator**:
   - Mix & match **Original** and **Spicy** onigiri.
   - Automatically computes ₱5 off for every set of 3 onigiris in the cart (e.g., 3 for ₱100, 6 for ₱200).
   - In-cart helper banner reminding customers if adding 1 more completes a discount!
   - One-click "⚡ Quick Add 3-Pack Onigiri" button.

3. **Interactive Cart & Drawer**:
   - Quantity adjustment controls (`+` / `-`).
   - Dynamic real-time calculation of subtotal, bundle discounts, and total payable amount.
   - Toast feedback when items are added.

4. **Checkout & Order Receipt Generator**:
   - Collects Customer Name, Phone Number, and Delivery / Store Pickup preference.
   - Supports popular local payment options (**GCash**, **Maya**, **Cash on Delivery/Pickup**).
   - Instant order confirmation modal with structured receipt and **1-click Copy Order Details** button for sending via Messenger or SMS.

5. **Store Information**:
   - Operating hours, pickup guidelines, and FAQ.
